================================================================================
  COMANDOS PARA FAZER COMMIT NO GITHUB - EXECUTE MANUALMENTE
================================================================================

IMPORTANTE: Reinicie o terminal/PowerShell após instalar o Git!

================================================================================
OPÇÃO 1: Usar Git Bash (Recomendado)
================================================================================

1. Abra o "Git Bash" (instalado com o Git)
2. Navegue até o projeto:
   cd "/c/Users/CleitonSanchesBR-iT/Documents/Projetos_automacoes/pesquisas_nps/pesquisas_nps"

3. Execute os comandos abaixo:

# Inicializar Git (se necessário)
git init

# Configurar remote
git remote remove origin
git remote add origin https://github.com/cleiton-sanches-brit/pesquisa_nps.git

# Configurar Git (primeira vez)
git config --global user.name "Cleiton Sanches"
git config --global user.email "seu-email@exemplo.com"

# Adicionar arquivos
git add .

# Fazer commit
git commit -m "Commit inicial - Sistema de Pesquisas NPS"

# Configurar branch main
git branch -M main

# Push para GitHub (vai pedir autenticação)
git push -u origin main

# Quando pedir:
# Username: cleiton-sanches-brit
# Password: COLE SEU PERSONAL ACCESS TOKEN (não sua senha!)

================================================================================
OPÇÃO 2: Usar CMD (Prompt de Comando)
================================================================================

1. Abra o CMD (Prompt de Comando)
2. Navegue até o projeto:
   cd C:\Users\CleitonSanchesBR-iT\Documents\Projetos_automacoes\pesquisas_nps\pesquisas_nps

3. Execute os mesmos comandos acima

================================================================================
OPÇÃO 3: Encontrar Git Manualmente
================================================================================

O Git geralmente está instalado em:
C:\Program Files\Git\cmd\git.exe
ou
C:\Program Files (x86)\Git\cmd\git.exe

Você pode usar o caminho completo:
"C:\Program Files\Git\cmd\git.exe" --version

================================================================================
CRIAR PERSONAL ACCESS TOKEN
================================================================================

1. Acesse: https://github.com/settings/tokens
2. Clique em "Generate new token" → "Generate new token (classic)"
3. Nome: pesquisa_nps
4. Expiração: escolha (ex: 90 dias)
5. Permissões: marque "repo" (acesso completo)
6. Clique em "Generate token"
7. COPIE O TOKEN (aparece apenas uma vez!)

Quando o Git pedir senha, cole o TOKEN (não sua senha normal).
