================================================================================
    COMANDOS CMD - RESOLVER ERRO "whitenoise" (LINHA A LINHA)
================================================================================

SIGA ESTES COMANDOS NA ORDEM, UM POR VEZ:

================================================================================
COMANDO 1: Abrir o CMD
================================================================================

- Pressione: Windows + R
- Digite: cmd
- Pressione: Enter

================================================================================
COMANDO 2: Ir para o diretório do projeto
================================================================================

Digite exatamente (copie e cole):

cd /d C:\Users\CleitonSanchesBR-iT\Documents\Projetos_automacoes\pesquisas_nps\pesquisas_nps

Pressione: Enter

Você deve ver:
C:\Users\CleitonSanchesBR-iT\Documents\Projetos_automacoes\pesquisas_nps\pesquisas_nps>

================================================================================
COMANDO 3: Instalar whitenoise
================================================================================

Digite exatamente:

venv\Scripts\python.exe -m pip install whitenoise

Pressione: Enter

Aguarde a mensagem: "Successfully installed whitenoise..."

================================================================================
COMANDO 4: Entrar na pasta django_app
================================================================================

Digite exatamente:

cd django_app

Pressione: Enter

Você deve ver:
C:\Users\CleitonSanchesBR-iT\Documents\Projetos_automacoes\pesquisas_nps\pesquisas_nps\django_app>

================================================================================
COMANDO 5: Iniciar o servidor
================================================================================

Digite exatamente:

..\venv\Scripts\python.exe manage.py runserver

Pressione: Enter

================================================================================
RESULTADO ESPERADO
================================================================================

Você deve ver:

Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.

================================================================================
SE AINDA DER ERRO
================================================================================

Tente instalar TODAS as dependências:

Volte para o diretório raiz:
cd ..

Instale tudo:
venv\Scripts\python.exe -m pip install -r requirements.txt

Depois tente iniciar novamente:
cd django_app
..\venv\Scripts\python.exe manage.py runserver

================================================================================
                    FIM
================================================================================
