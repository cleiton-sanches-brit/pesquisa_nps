OPÇÃO 1: RENDER.COM (RECOMENDADO - GRATUITO)
================================================================================

✅ 100% Gratuito
✅ Deploy automático do GitHub
✅ Suporta PostgreSQL (Supabase)
✅ HTTPS automático
✅ Interface fácil
⚠️ Pode hibernar após 15min (mas acorda rápido)

GUIA COMPLETO: DEPLOY_RENDER.md

PASSO A PASSO RÁPIDO:
1. Acesse: https://render.com
2. Crie conta com GitHub
3. New → Web Service
4. Conecte repositório: pesquisa_nps
5. Configure:
   - Build: pip install -r requirements.txt
   - Start: cd django_app && python manage.py migrate && python manage.py collectstatic --noinput && gunicorn nps_admin.wsgi:application --bind 0.0.0.0:$PORT
6. Adicione variáveis de ambiente
7. Deploy automático!
