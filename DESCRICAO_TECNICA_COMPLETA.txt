1. VISÃO GERAL DO PROJETO
================================================================================

NOME DO PROJETO: Sistema de Pesquisas NPS (Net Promoter Score)
VERSÃO: 1.0 Beta
LINGUAGEM PRINCIPAL: Python 3.12
ARQUITETURA: Microserviços (Django + FastAPI)
BANCO DE DADOS: SQL Server (Azure)
AMBIENTE: Desenvolvimento Local + Deploy em Produção

OBJETIVO PRINCIPAL:
Desenvolver uma plataforma completa e segura para coleta, análise e gestão de 
pesquisas NPS, permitindo a criação de formulários personalizados, coleta de 
respostas via links únicos e expiráveis, e geração de relatórios analíticos 
em tempo real.

PROBLEMA RESOLVIDO:
- Centralização de pesquisas NPS em uma única plataforma
- Automação do processo de coleta e análise de dados
- Geração automática de relatórios e dashboards
- Integração segura com sistemas existentes via API
- Controle de acesso único por email com links expiráveis

4. MODELOS DE DADOS
================================================================================

4.1 ESTRUTURA PRINCIPAL:

Survey (Pesquisas):
- id, title, description, is_active
- created_at, updated_at, created_by
- expires_at, allow_multiple_responses

SurveyInvitation (Convites Únicos):
- id, survey_id, email, unique_token (UUID4)
- is_used, used_at, created_at, expires_at
- Validação: unique_together ['survey', 'email']

Question (Perguntas):
- id, survey_id, question_text, question_type
- is_required, order, created_at
- Tipos: 'nps', 'text', 'choice', 'rating'

Choice (Opções de Múltipla Escolha):
- id, question_id, choice_text, value, order

SurveyResponse (Respostas Completas):
- id, survey_id, invitation_id, respondent_id
- respondent_email, submitted_at
- ip_address, user_agent

Answer (Respostas Individuais):
- id, response_id, question_id
- answer_text, answer_value, answer_choice_id

NPSResult (Resultados Calculados):
- id, survey_id, period_start, period_end
- total_responses, promoters, passives, detractors
- nps_score, calculated_at

4.2 RELACIONAMENTOS:
- Survey → Questions (1:N)
- Question → Choices (1:N)
- Survey → Invitations (1:N)
- Survey → Responses (1:N)
- Response → Answers (1:N)
- Survey → NPSResults (1:N)
