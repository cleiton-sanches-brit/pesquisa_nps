# 📄 Exportar Preview Manualmente (Método Simples)

## 🎯 Método Mais Simples - Sem Instalar Bibliotecas

Se você não quiser instalar bibliotecas Python, use este método:

### Passo 1: Abrir o Preview
1. Abra o arquivo `preview_email_convite.html` no navegador
   - Duplo clique no arquivo, ou
   - Arraste para o navegador

### Passo 2: Exportar como PDF

#### Opção A: Imprimir e Salvar como PDF
1. Pressione `Ctrl+P` (ou `Cmd+P` no Mac)
2. Escolha "Microsoft Print to PDF" ou "Salvar como PDF"
3. Clique em "Salvar"
4. Escolha onde salvar o arquivo

#### Opção B: Usar Extensão do Navegador
**Chrome/Edge:**
- Instale extensão "Print Friendly & PDF"
- Clique no ícone da extensão
- Exporte como PDF

**Firefox:**
- Instale extensão "Print Edit"
- Use para exportar

### Passo 3: Capturar como Imagem (PNG)

#### Método 1: Ferramenta de Captura do Windows
1. Pressione `Windows + Shift + S`
2. Selecione a área do email
3. Salve a captura

#### Método 2: Extensão do Navegador
**Chrome/Edge:**
- Instale "Full Page Screen Capture"
- Capture a página completa
- Salve como PNG

**Firefox:**
- Instale "FireShot"
- Capture a página completa

## 📧 Compartilhar com o Time
