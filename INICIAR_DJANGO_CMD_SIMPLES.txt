================================================================================
    COMANDOS PARA INICIAR DJANGO - CMD WINDOWS (LINHA A LINHA)
================================================================================

SIGA ESTES COMANDOS NA ORDEM, UM POR VEZ:

================================================================================
COMANDO 1: Abrir o CMD
================================================================================

- Pressione: Windows + R
- Digite: cmd
- Pressione: Enter

================================================================================
COMANDO 2: Ir para o diretório do projeto
================================================================================

Digite exatamente (copie e cole):

cd /d C:\Users\CleitonSanchesBR-iT\Documents\Projetos_automacoes\pesquisas_nps\pesquisas_nps

Pressione: Enter

Você deve ver algo como:
C:\Users\CleitonSanchesBR-iT\Documents\Projetos_automacoes\pesquisas_nps\pesquisas_nps>

================================================================================
COMANDO 3: Entrar na pasta django_app
================================================================================

Digite exatamente:

cd django_app

Pressione: Enter

Você deve ver:
C:\Users\CleitonSanchesBR-iT\Documents\Projetos_automacoes\pesquisas_nps\pesquisas_nps\django_app>

================================================================================
COMANDO 4: Iniciar o servidor
================================================================================

Digite exatamente:

..\venv\Scripts\python.exe manage.py runserver

Pressione: Enter

================================================================================
RESULTADO ESPERADO
================================================================================

Você deve ver:

Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.

================================================================================
SE DER ERRO NO COMANDO 4
================================================================================

Tente esta alternativa:

python manage.py runserver

(Isso funciona se o Python estiver instalado no sistema)

================================================================================
ACESSAR O ADMIN
================================================================================

Com o servidor rodando, abra o navegador e acesse:

http://localhost:8000/admin/

================================================================================
PARAR O SERVIDOR
================================================================================

No CMD onde o servidor está rodando:
- Pressione: Ctrl + C

================================================================================
                    FIM
================================================================================
