================================================================================
  QUICK START - RAILWAY DEPLOY
================================================================================

PASSO 1: CRIAR PROJETO
================================================================================

1. Acesse: https://railway.app
2. Faça login com GitHub
3. Clique em "+ New Project" (canto superior direito)
4. Escolha "Deploy from GitHub repo"
5. Autorize Railway (se primeira vez)
6. Selecione: cleiton-sanches-brit/pesquisa_nps
7. Clique em "Deploy"

================================================================================
PASSO 2: ENCONTRAR VARIABLES
================================================================================

1. Clique no NOME DO PROJETO (não no workspace)
2. Clique na aba "Settings" (no topo)
3. Role a página até encontrar "Variables"
4. Clique em "+ New Variable"

================================================================================

================================================================================
PASSO 4: REDEPLOY
================================================================================

1. Vá em "Deployments"
2. Clique nos três pontinhos (⋯) no último deploy
3. Selecione "Redeploy"

OU simplesmente faça um novo commit no GitHub

================================================================================
PASSO 5: OBTER URL
================================================================================

1. Vá em "Settings"
2. Seção "Networking" ou "Domains"
3. Copie a URL (ex: https://seu-app.railway.app)
4. Atualize ALLOWED_HOSTS com a URL real

================================================================================
SE NÃO ENCONTRAR
================================================================================

1. Certifique-se de ter clicado no PROJETO (não no workspace)
2. Procure pela aba "Settings" no topo
3. Role a página Settings até encontrar "Variables"
4. Se ainda não encontrar, tente:
   - Atualizar a página (F5)
   - Verificar se o projeto foi criado corretamente
   - Tentar criar um novo projeto
